Ligação ao repositório

Esta interface não tem servidor próprio — lê e escreve diretamente o ficheiro products.json no teu repositório GitHub, através da API do GitHub. O token fica guardado só neste browser (localStorage), nunca é enviado para mais lado nenhum além do próprio GitHub.

Cria um token em GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token. Limita-o a este repositório e dá-lhe permissão Contents: Read and write. Define uma data de expiração razoável.
